# Security

Do not include API keys, `.env` files, browser storage, seat tokens, invitation links, SQLite databases, or private game exports in issues or pull requests. The application does not require an external AI API key.

For a suspected security vulnerability, use GitHub's private vulnerability reporting feature on this repository's Security tab. Do not post exploit details or credentials in a public issue. Rotate any exposed credential with its provider; deleting a file or commit is not sufficient.

Self-hosters should use HTTPS, restrict access as appropriate for their group, keep dependencies updated, and secure saved-game storage and backups. This is community software, not a guarantee of security or rules completeness.
